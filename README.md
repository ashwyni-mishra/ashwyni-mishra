# Ashwani Mishra - Cybersecurity Portfolio

A modern, responsive personal portfolio website with a cybersecurity theme (dark mode, green/blue accents), built using React, Vite, and Tailwind CSS. The portfolio features a Firebase-backed Admin Dashboard to dynamically update content.

## Features
- **Public Portfolio:** Terminal-style UI featuring Experience, Education, Projects, and Skills.
- **Admin Dashboard:** Secure CMS with Firebase Authentication to update sections dynamically.
- **Responsive Design:** Mobile-first approach utilizing Tailwind CSS.
- **Firebase Backend:** Powered by Firestore for real-time updates.

## Local Setup
1. Clone the repository: `git clone https://github.com/ashwyni-mishra/ashwyni-mishra.git`
2. Run `npm install`
3. Read `SETUP.md` for Firebase configuration (`.env.local`) details.
4. Run `npm run dev` to start the Vite development server.

## Architecture
- React 18
- Vite
- Tailwind CSS
- Firebase (Authentication & Firestore)
- Framer Motion

For deployment and database access instructions, refer to `SETUP.md`.
